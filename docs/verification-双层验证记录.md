## 四、产品化打磨轮（2026-09-16 第 2 轮反馈）追加验证
本轮 e2e 升级至 18 步（新增 7c2 双人建卡、7e 删卡不复活、10 个人中心），一次运行：
- `7c2` B 新建卡片实时同步回 A（1→2）；
- `7e` A 删除卡片 → B 端实时消失；A 刷新重开 → 被删卡片**不复活**（服务端 welcome 过滤墓碑元素）；
- `10` 个人中心：资料展示（头像/用户名/昵称/角色/注册时间/空间·文档·操作统计）+ 昵称编辑即时生效（`/api/auth/profile` GET/PUT）。
- 本轮修复清单（Playwright 真机抓出）：
  1. **删除键失效**（三应用通病）：`applied` 帧带 `clientId!==me` 守卫 → 自己的 DELETE 不镜像本地 → 点 ✕ 后本地卡片不消失（刷新后因墓碑复活更明显）；改为无条件本地镜像（PUT/ADD 幂等）。
  2. **看板 ✕ 按钮按下触发拖拽**：mousedown 落在按钮上仍进入拖拽分支 → click 被吞；加 `closest('button')` 跳过。
  3. **✕ 仅 hover 可见**：改为常显浅灰、hover 变红（看板 + 白板）。
  4. **看板刷新后卡片全部消失**：welcome 快照来自 HashMap，CARD 可能先于 COLUMN 渲染成孤儿节点；render 改为先列后卡两趟渲染。
  5. **新用户无默认空间**：注册即自动创建「我的空间」，新用户落地即可建文档/看板（此前直接撞空空间失败）。
  6. **并发拖拽重叠自愈**：同级相邻卡几何重叠时自动按 order 重排（`settleOverlaps`）。
- 运行结果：**18/18 PASS**（每次全量跑通）；JUnit 侧随版本同步回归。
