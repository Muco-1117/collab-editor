# 2026-10-22 两小时项目完善记录

本轮按照“持续完善功能、使用体验和页面，两小时结束后汇报”的要求推进。本轮修改工程和使用文档，未撰写论文。

## 工作台与页面

- 保留用户选定的浅色简洁风格。空间首页负责综合浏览；文档、白板、看板分别有独立地址、专属创建、名称查找和布局。白板显示实际画布缩略图，看板显示实际任务列与数量，避免左侧导航重复首页筛选。
- 从编辑器、个人页和加载失败页返回时，保留原栏目与空间；刷新、前进、后退保持位置。
- 编辑器统一浅灰白蓝外壳；手机侧栏支持焦点管理、Esc 关闭，关闭后背景恢复可操作。
- 修复文档窄屏自动换行后高度不变导致的裁切，320px、远端长文本更新、恢复桌面宽度均验证完整显示。
- 被移出空间或内容被删除时，立即退出编辑界面，显示明确原因和返回入口；历史和导出入口同步禁用。

## 功能与操作

- 所有者可修改成员的编辑/只读权限、移出成员；所有者身份受保护，普通成员没有管理入口。权限在已打开的多个页面实时生效。
- 三种内容改名实时更新其他协作者的顶部标题和当前列表项，重新连接后仍显示权威标题。顶部保持静态展示，不恢复冗余的改名输入框。
- 创建段落、白板卡片、看板列表和任务使用一次完整元素提交；移动、缩放和封面更新尽量一次提交，并读取最新字段，减少覆盖其他成员刚完成的修改。
- 修复中文输入法组合输入、Shift+Enter、选区拆段、标题保存/取消、新列表编号、排序号碰撞和新建后的焦点。
- 拖动期间远端删除、权限变化、Esc、指针取消、失焦和退出页面不会误提交未完成的拖动。
- 图片上传支持格式、空文件、大小提示；离开目标或失去权限时不使用迟到结果。图片读取失败可独立重试。
- 历史列表和版本预览分别支持重试；有新修改时提示刷新历史；恢复期间防重复提交、误关和切换版本，失败在弹窗内提示。
- 复制链接失败时显示实际内容链接，支持选中后手工复制。改名、删除失败保留目标和输入，支持重试。
- 提示消息合并重复内容、最多三条，支持悬停和焦点暂停、键盘关闭；弹窗关键错误使用内联反馈，避免遮挡操作。

## 协作与数据可靠性

- 临时断线保留当前页面中未确认的修改，重连并确认权限后按原 clock/opId/载荷有序重发，避免重复落库。
- 已确认状态与本地待确认状态分开；明确拒绝后回退至已确认内容。旧连接的迟到消息不再影响新连接。
- 补齐握手、心跳和写入确认超时处理，以及有界自动重试、手动重连、跨账号保护。
- 全量快照保留删除标记，防止旧修改重发时在客户端重新显示已删除元素。
- 正文编辑会更新最近修改时间；重复确认不伪造更新时间。删除内容及时关闭在线房间，撤销成员权限阻止排队写入。
- 登录恢复时的临时网络错误保留凭据；旧账号迟到响应不能覆盖新账号。导出和图片共用鉴权流程，取消请求不会被共享登录刷新阻塞。
- 修正空参数、非法空间 ID 和密码边界。BCrypt 密码最多 72 个 UTF-8 字节，前后端提示一致。

## 启动与交付

- 新增 `scripts/start-backend.ps1`、`scripts/start-frontend.ps1`，支持环境预检查、明确端口冲突、可配置工具路径和后端代理。
- 新增 `collab-editor.code-workspace`，VS Code 可分别启动前后端或运行“同时启动前后端”。
- IDEA 使用 `CollabServer-local`，显式加载外部本地配置。Maven 打包排除本地密码配置；本轮新 JAR 已检查不包含 `application-local.*`。
- 详见 [IDEA 和 VS Code 启动指南](local-development.md)。REST、WebSocket 和部署文档已同步。
- 前端产物：`frontend/dist/`；后端产物：`server/target/server-0.1.0.jar`。

当前用户的 8080 后端和 5173 前端未被停止。后端新接口和协议需要在 IDEA 重启 **CollabServer-local** 后生效，再刷新 [本地页面](http://localhost:5173)。无需删除或重新初始化现有数据库。

## 仍保留的边界

- 同一个元素仍采用完整状态的 LWW 合并，不提供字符级多人合并；同时修改同一段文字可能由较新的整项状态覆盖。
- 未确认修改只保留在当前页面内存；强行关闭或刷新仍可能丢失未同步输入，界面会在离开时提醒。
- 多元素拆段、删列和必要重排可能产生多条操作，不是跨元素事务。
- 超过72个 UTF-8 字节的历史密码现在会被拒绝，避免BCrypt静默截断；未修改任何已有账号的密码。
- 验证基于本机单服务实例；未执行公网部署或跨实例协同验收。
