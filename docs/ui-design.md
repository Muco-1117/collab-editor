# 工作台主页设计与开源来源

本轮按“浅色简洁，类似 Notion / 飞书”的偏好改造 Vue 3 工作台。

## 开源方案选择

| 项目 | 协议 | 评估 |
|---|---|---|
| [shadcn-vue](https://github.com/unovue/shadcn-vue) | MIT | 选用。Vue 组件源码可本地修改，侧栏布局适合内容协作产品 |
| [Nuxt UI Dashboard](https://github.com/nuxt-ui-templates/dashboard) | MIT | 布局成熟，但引入完整模板需要迁移 Nuxt |
| [Sakai Vue](https://github.com/primefaces/sakai-vue) | MIT | Vue 兼容，管理后台和数据图表布局较重 |
| [Tabler](https://github.com/tabler/tabler) | MIT | Bootstrap 后台模板成熟，与当前 Vue 样式体系适配成本较高 |

从 shadcn-vue 的 [Sidebar](https://github.com/unovue/shadcn-vue/blob/dev/apps/v4/registry/new-york-v4/ui/sidebar/Sidebar.vue)、[SidebarInset](https://github.com/unovue/shadcn-vue/blob/dev/apps/v4/registry/new-york-v4/ui/sidebar/SidebarInset.vue) 和 [sidebar-07](https://github.com/unovue/shadcn-vue/blob/dev/apps/v4/registry/new-york-v4/blocks/sidebar-07/components/AppSidebar.vue) 移植侧栏/内容框架与分区方式，落为 `WorkbenchLayout.vue` 和普通 CSS。保留当前 Vue Router、业务接口、图标与菜单交互，不引入整套示例后台或其虚构数据。原始版权声明见 `frontend/src/styles/vendor/shadcn-vue.LICENSE`。

## 视觉与信息结构

- 白色 `#ffffff` 为内容底色，浅灰 `#f7f8fa` 为导航底色，深灰 `#252a34` 为文字，细分隔线 `#e9ebef`，主操作蓝 `#4263eb`；白板与看板图标分别用柔和金色和紫色区分。
- 使用系统 `Segoe UI`、`Microsoft YaHei UI` 字体，不依赖在线字体。空间标题为 28px，区块标题为 15px，内容与工具文字分层。
- 桌面侧栏 232px，内容最大 1220px；浅色导航承载空间切换、独立内容栏目、成员、统计和所有者回收站。空间首页突出当前空间、三类创建入口、继续工作和最近更新；完整分类由侧栏承担。
- 首页没有第二套类型筛选、显示方式切换和名称排序。文档、白板、看板栏目按各自内容结构展示，提供名称查找及名称/更新时间排序。全局搜索范围仍为当前用户可见内容；成员只展示当前空间，统计明确标示全部可见空间范围。
- 创建、邀请、重命名、删除沿用现有权限。头像和名字仍进入个人主页。
- 820px 以下使用抽屉导航；600px 以下收紧间距、隐藏次要描述，保持创建、栏目查找、菜单和个人主页可操作。遵循系统减少动画设置。

## 交互完善

- 左侧文档、白板、看板分别进入 `/library/doc`、`/library/board`、`/library/kanban`；栏目来自 URL，当前空间写入 `?space=`，支持刷新、直接打开和浏览器前进/后退。切换空间时保留所在栏目。
- 空间首页是接续工作的入口：“继续工作”最多 4 项、“最近更新”最多 8 项，最近更新按当前空间真实更新时间排序。继续工作按本机当前账号隔离，只保存内容键、空间、类型和打开时间，匹配当前授权列表后展示；不保存正文或标题，不把其他账号、已删除、失去权限的内容带入。没有记录时不展示空的继续工作区块。
- 独立栏目使用对应标题、说明、名称查找和单一创建入口。文档展示真实正文摘要、段落/图片数量和字数；白板展示实际画布缩略图；看板展示真实任务列和所有有效列的任务分布。列名称可自定义，不把最后一列推断为“完成”，不生成完成率。预览复用已有历史回放接口，按进入视口的内容加载；失败显示重试，原内容仍可打开。
- 首页和栏目提供“刷新内容”，更新空间、成员与内容，并重新读取可见预览；即使修改发生在同一秒，旧摘要也不会因时间戳相同而被保留。窗口重新获得焦点且距上次刷新超过 30 秒时会补充刷新。收到内容或成员接口的 `403/404` 后清空对应缓存；普通网络错误显示重试并保留已有列表。
- 更多菜单记录打开时的滚动位置，忽略此前滚动产生的迟到通知，避免点击页面底部省略号后菜单闪退。实际外部滚动或点击仍关闭菜单；键盘导航、手机边界翻转和菜单内部滚动保留。
- 按账号在当前标签页保存工作台返回位置，个人主页、编辑器和打开失败页的“返回工作台”均回到原栏目和原空间。路由切换会关闭未提交弹窗，提交过程中阻止误导航。
- 搜索支持 `Ctrl/Cmd + K` 聚焦、方向键选择、`Enter` 打开和 `Esc` 关闭。点击外部关闭，一键清空；关闭后迟到的响应不会重新展开，新的关键词不会显示上次结果。
- 空间、内容、成员、统计和搜索失败时显示独立的重试入口，避免将连接失败显示成空数据。
- 创建、邀请等表单在提交时禁止重复发送与误关闭，失败后保留输入。
- 弹窗自动聚焦并限制键盘焦点，关闭后回到触发位置；嵌套弹窗只关闭最上层。手机导航收起时不接收焦点，展开时锁定背景，切换桌面尺寸会恢复正常滚动。
- 个人主页沿用浅灰蓝色，显示昵称字数与保存状态，支持取消修改；未保存离开时提醒，保存期间避免冲突操作。

## 回收站与账号状态

所有者从左侧“回收站”进入 `/trash?space=<id>`，保持当前空间语义。列表显示真实标题、类型和删除时间，可按名称查找并恢复。恢复后给出打开入口，内容回到原类型和空间，正文、图片和历史保留；暂不提供永久删除或自动清空。编辑者和只读成员不能管理回收站，不能通过手输路由或 API 绕过权限。加载失败和恢复失败分别提示，切换空间时不显示旧空间迟到的结果。

多标签页共享账号状态；另一页退出或换账号后，当前页先卸载旧编辑器和 WebSocket，再进入对应登录页或新账号首页。同账号正常 token 换发保留当前页面和连接。昵称、头像在重新打开个人主页时读取最新资料，暂不跨标签即时推送，避免覆盖当前页草稿基线。头像通过统一 `apiBlob` 流程处理认证刷新，加载失败回退昵称首字。

协作概览明确标示统计范围。最近 7 个数据库自然日连续显示，无操作日期为 0 且不画非零柱；同昵称成员按账号 ID 区分。次数来自已保存协作操作，包含系统初始化，不代表任务完成度。

## 白板视图导航

白板画布随实际元素范围增长，右下方工具栏提供 10%–200% 缩放、100% 原始比例和“适应”。支持 Ctrl/Command + 滚轮定点缩放、空格 + 左键拖动、中键拖动，以及显式平移模式；手机可在平移模式或空白处通过触屏浏览。卡片拖动、尺寸调整、双击创建和图片插入按当前缩放换算实际坐标。

缩放和视口平移仅改变本地视图，不产生协同写操作，只读成员同样可用。最小比例是 10%；极端跨度的白板在最小比例下仍可能需要平移浏览，不能保证任意范围一次全部放入视口。SVG/PNG 导出保留实际布局，超过导出像素限制时明确报错，不根据屏幕缩放改写坐标。

## 文档内查找

正文上方保留紧凑的“查找”入口，展开后显示关键词、当前位置/总数、上一处、下一处和关闭。`Ctrl/Cmd+F` 在当前文档没有模态层时打开；`Enter` 和 `Shift+Enter` 循环定位，`Esc` 关闭并恢复原编辑焦点与选区。搜索输入保留焦点，可连续查找；当前位置的段落用浅蓝底标识，正文文本框选中实际命中范围。

匹配只针对可见 `TEXT` 段落，忽略大小写，特殊字符按字面解释，关键词最多 128 个 UTF-16 代码单元；不跨段、不搜索图片说明、不做替换。中文输入法组合期间不触发查找导航或关闭。远端修改会更新结果和序号，不主动抢焦点或滚动画面；只读成员同样可使用，查找不产生协同写入。320px 下输入与导航自然换行，正文和底部插入入口保持可见。

## 看板列表导航与移动

每张可编辑卡片提供原生“移至列表”选择框，选择目标后追加到其末尾，并在看板内部跟随卡片和键盘焦点。选回当前列表不修改排序，位置编号帮助区分同名列表；原有箭头、上下排序和拖动继续可用。提交前重新读取卡片最新字段与目标列表，保留其他成员刚更新的文字、颜色和封面；已收到远端删除的目标不可再选，断连或失去写权限时禁用移动，只读成员不显示移动入口。

顶栏“跳转列表”显示实际列表名与任务数，只滚动本地看板，不发送协同操作；只读或临时失联时也能浏览。长列表在列内滚动，封面以固定比例容器保持布局稳定；320/390px 下控件换行，不撑宽整个页面。正常跨列移动提交一个完整 `STATE`；极端排序值需要沿用既有重排保护时，可能先提交目标列表的排序修复操作。

交互专项检查：`dashboard-polish-checks.mjs`、`profile-polish-checks.mjs`、`overlay-checks.mjs` 均使用模拟接口和独立浏览器环境，可验证延迟、错误重试、焦点与未保存状态，不修改实际账号。对应截图和结果位于 `artifacts/ui-dashboard-polish-20261022/`、`artifacts/ui-profile-polish-20261022/`、`artifacts/ui-overlay-polish-20261022/`。

独立栏目检查：`node tests/e2e-ui/library-navigation-checks.mjs` 使用模拟 API/WebSocket，覆盖首页与栏目职责、刷新/前进后退/切空间、真实结构预览、创建/打开/返回/重命名/删除、只读及编辑权限、加载失败重试、迟到响应、弹窗导航和 1024/820/600/390/320px 布局。第二轮结果位于 `artifacts/round2-20261022/library-navigation/`；首页/回收站、白板视图、跨标签状态和统计/头像专项分别归档到同级 `home-trash/`、`board-viewport/`、`cross-tab-auth/`、`stats-avatar/`。预览几何、删除过滤、返回地址、最近打开记录隔离及缩放坐标另有前端单测。浏览器模拟验证与真实后端验证分开记录。

文档查找与看板导航专项为 `document-find-checks.mjs`、`kanban-navigation-checks.mjs`，模拟接口结果及桌面/手机截图分别归档到 `artifacts/round2-20261022/document-find/`、`kanban-navigation/`。已有 `editor-quality-checks.mjs` 用于检查段落拆分、输入法、拖动取消、排序与字段保留是否回归，新增功能不改变这些断言。
